# Changelog

All notable changes to SkyDeck. The format follows [Keep a Changelog](https://keepachangelog.com/), and the project will use [Semantic Versioning](https://semver.org/) from the first release (see CONTRIBUTING.md, "Releases"). Nothing has been released yet, so everything below is under Unreleased.

## Unreleased

### Changed

- Cleanups after the 2026-11-25 merges: eslint runs with no warnings (`toggleVariants` moved to `toggle-variants.ts`, unused `buttonVariants`/`badgeVariants` exports dropped, two effect dependency warnings fixed without changing behaviour); the phone map controls hide under a tall sheet based on the measured top bar height instead of a fixed 360 px (#100 review); the README banner test no longer reads a desktop screenshot left on disk by an earlier test (#97 review).

- Faster map page on phones: the aircraft loop now runs on a 90 ms timer instead of asking for a frame 60 times a second, skips updates that would not move, turn or change any aircraft by a visible amount (1 px at the current zoom, 2 degrees), and labels no longer cross-fade, which kept MapLibre repainting after every update. The map library loads after the first paint (after the first-run guide's fade-in on a first visit), and the Supabase library loads only when sign-in is used. Lighthouse on the local production build with the stub feed: mobile 45 to about 61, desktop 61-88 to about 94; total blocking time on mobile 8 s to about 2.2 s.
- AI calls go through one global `AiHub` Durable Object, so budgets, pacing and caches are shared by every visitor. Each provider has a per-minute limit; Workers AI is skipped until 00:00 UTC once its daily allowance is gone, and Gemini's daily quota is rechecked hourly. With no provider free the answer is "AI is busy, try again in a minute." ACARS headlines are cached per message in memory and shared; they are at most 12 words, explanations 1 to 2 sentences for routine messages and up to 5 for emergency, caution and weather. The ACARS panel retries busy headlines with a growing gap, and the message card has a Try again button (#83).
- With an adsb.lol key, refreshes of tiles that already have a copy are paced so what is left of each hourly and daily window is spread evenly, with a reserve for tiles that have no copy; copies up to an hour old are shown with their real age in between, so a wide view cannot use the day's quota in minutes (#85).
- With an adsb.lol key, requests are counted against the key's published limits and not sent once a limit would be passed; the map then shows saved copies up to an hour old (protects a free key from being revoked).
- The live feed cache, provider pacing and refresh budget are shared by every server instance: on Cloudflare the feed loads inside one `FeedHub` Durable Object (18f, 19h).
- Zoomed out (below zoom 8), overlapping aircraft are thinned on a screen grid instead of all being drawn or hidden by icon collision; selected and emergency aircraft always stay (#75, #76). Terrain tiles load at half the request count (#74).
- Old editor tooling removed (Phase 15a): the build uses a plain `vite.config.ts`, `lightningcss` is a direct dependency, and an old error hook, project folder and notes are gone. The production build is unchanged (same files, same size, same Worker settings).
- The dark theme's destructive red is a little darker, so white text on it reaches 4.5:1 (it was 3.7:1).
- `public/robots.txt` is replaced by a `/robots.txt` route that also points at the sitemap and keeps crawlers off `/api/`.
- Zoomed-in views request fixed shared tiles; cached tiles are aged, and a busy provider is answered from a tile up to 30 s old (#17).
- Requests to each data provider are spaced out, and identical in-flight requests are shared (#3).
- The last good aircraft stay on screen for up to 2 minutes when every provider fails (#18).
- The route lookup answers with a one-hour browser cache header (#18).
- Dependencies updated to clear 27 of 28 known vulnerabilities, including zod 4 (server input validation) and vite 8.1.6.
- The status chip says "Loading" before the first response, and the search placeholder fits a 375 px screen (#15).

### Fixed

- Closed-page alerts could stay silent: the `PushHub` object kept which aircraft matched each rule only in memory, and an idle Durable Object is unloaded after 70 to 140 seconds, so most two-minute checks started empty, only learned, and sent nothing. The matches are now saved with the cooldowns (ignored once older than 10 minutes).
- The shared AI answer cache used a 32-bit FNV hash of the browser-sent prompt as its key, so a crafted prompt could collide with a real message's and have its answer shown to other visitors. The key is now SHA-256.
- Notification clicks: a tab the service worker does not control could not be navigated and nothing opened; a new tab opens then. A notification address with a backslash ("/\\host" reads as "//host") is refused.
- Warning text (closed-page alert errors, flight progress, replay badge) used a fixed light amber that was unreadable in the light theme; it uses the theme's `--warning` colour, and the closed-page alert error is announced to screen readers.
- Watchlist sync on sign-in: when this browser had more new items than the account had room for (50), the database refused the whole upload, so none of them were saved and the sync showed an error. Now only what fits is uploaded, and a notice names the items that were left out.
- Map without its basemap: when the OpenFreeMap style cannot be fetched (the service is down, or a network blocks it), the map now falls back to a plain background in the basemap's colours instead of staying without a style. Before, MapLibre then drew no aircraft and ran no camera moves, so going to a saved view, a search result or an airport did nothing; this is also why the "saved views" flow failed in cloud containers, which cannot reach OpenFreeMap. A new flow blocks the style and checks that a saved view still moves the map.
- Closed-page alerts, security review (2026-11-25): the web push migration's account limits were subqueries in the insert policies, which Postgres refuses with "infinite recursion", so every subscribe would have failed; a follow-up migration (`20261125010000_web_push_limits.sql`) moves them into triggers that also set `created_at` and `updated_at` on the server, so back-dated rows cannot jump the check's caps. The check now takes every user's first rule before anyone's second, so one account cannot use up all feed circles; push requests never follow redirects; database reads and pushes time out after 10 s; and signed VAPID tokens are reused per push service to save CPU.
- Development server cold start (0h, Windows): the map's web worker no longer throws `ReferenceError: document is not defined`. Vite served it with its live-reload client, which touches `document` on every CSS update (Tailwind sends several on a cold start); the MapLibre worker is now served unchanged in development.
- Unit tests on Node 26 when `--no-experimental-webstorage` does not reach the test process: the test setup points `localStorage` and `sessionStorage` back at jsdom's.
- Development server cold start (0h): the first page load no longer aborts every module request and reloads (four dependencies Vite found late are now pre-bundled); server function calls made before the server side compiled their file no longer fail with `Invalid server function ID` (those files are compiled at start-up); a page reloaded mid-load now logs one `[request aborted]` line instead of three stack traces.
- Design QA (15h): on phones the feed notices ("Live data is busy", missing areas, partial view) now sit under the top bar instead of over the map credit at the bottom, and disabled toolbar buttons such as Replay keep their solid panel and only dim the icon, so they no longer turn dark over a dark map in the light theme. With an aircraft or airport panel open, the scale bar moves left of the desktop side panel instead of sitting half behind it, and on phones the zoom buttons, scale and map credit sit above the bottom sheet (hidden while the sheet is pulled up to full height).
- The project's address in the footer, the README clone line and the issue template config is now `https://github.com/srii-dev/sky-deck` (the old account name only worked through a redirect).

- Location said "blocked" when the browser allowed it but Windows had location off for the browser; airspace areas stayed on the map after zooming out past the load limit (#73).
- Parked or holding aircraft were shown as "Last seen" and dimmed after 5 s; Follow mode no longer leaves the data area behind; a failed route lookup is retried after a minute instead of cached for an hour; FAA arrival delays were labelled as departures; a bad ACARS timestamp no longer breaks the message card; toolbar, legend, banner and panel no longer overlap at 1024x768 or on phones; the search box is announced as a combobox (#70).
- Closing the Settings, Watchlist, Collection, Alert rules, Account, Credits or Shortcuts dialog gives keyboard focus back to the button that opened it (it fell to the page before).

- The canonical link of every page named the home page; it now names the page itself, and a missing page has none.
- A search with only punctuation no longer reaches the data provider, one bad entry in a provider answer no longer discards the rest, and the refresh budget's demand map has a hard size limit.

- A hydration warning in development: the theme script sets the colour scheme on the html element before React starts, which the page now expects.
- The two `profiles` row-level security policies now call `auth.uid()` once per query instead of once per row (database advisor warning).
- Legal page titles no longer repeat the site name.
- A Cessna 172 or 177 was classified as a heavy jet (the C-17 pattern matched it) and drawn with the heavy jet icon.
- The tracked flights hook changed the length of a React dependency list when flights were added or removed.
- A failed feed request no longer falls back to a cached result of any age; the limit is 30 s (#17).
- The Filters button no longer wraps to a second row while loading at 1280 px, and the map credit no longer runs over the altitude legend on phones (#15).
